# chow9527

给汽车照片 P 上《逃学威龙》造型的周星驰和摩托，看起来像在给车辆违停抄牌。

## 安装

```sh
npx skills add https://github.com/jaccong/chow9527 --skill chow9527
```

## 用法

发一张汽车照片，说一声要 P 抄牌，就会往车旁边加上：

- 周星驰《逃学威龙2》交警扮相：白色头盔、红黄反光背心、白衬衫、黑裤黑鞋，手持罚单本；
- 白色警用摩托车（带后尾箱），停在人物旁边。

原照片的车、背景、角度保持不变。想换造型（比如换成铁骑）时给一张
参考图，只换样式，位置不动。

默认参考剧照：https://877622.xyz/chow9527/chow9527-still.jpg

## 来源

剧照为《逃学威龙2》公开剧照，仅作造型参考。
